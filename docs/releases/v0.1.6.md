First public release of **Autel MaxiCharger over HTTPS** for Home Assistant.

## Features

- Local HTTPS Start/Stop buttons, a 6–32 A current-limit input, and an Autostart
  configuration switch.
- Charging status, vehicle connection, power, current, voltage, session energy
  and duration, and meter energy sensors.
- CPU, memory, flash, network signal quality, and HTTP request-rate diagnostics.
- High, Medium, Low, and Custom polling schedules, with slower reads while
  unplugged and faster updates while charging.
- Serialized HTTP requests, configurable timeouts, explicit token renewal, and
  redacted debug logging and downloaded diagnostics.
- Start disabled while charging; both charging buttons disabled while unplugged
  or connection is unknown. Stop stays enabled when connected and stopped.

## Installation

Requires **Home Assistant 2026.10 or newer**. Add
`danwoodsy/autel-maxicharger-ha` as an **Integration** custom repository in HACS,
download it, restart Home Assistant, then add **Autel MaxiCharger over HTTPS**.
Configure the charger address, username, and local web PIN. Self-signed HTTPS
certificates are supported.

For manual installation, extract the attached `autel_http.zip` into `/config`.
It includes the `custom_components/autel_http` directory.

## Compatibility and upgrades

The interface has been physically tested on MaxiCharger model
**EW07-C050000A002**, firmware **V1.05.38**. Other models and firmware need
validation. Automated tests use a simulated charger with Home Assistant 2026.10.

Existing users keep the `autel_http` integration domain and the Wi-Fi quality
entity's ID. The duplicate numeric Network signal level entity is removed;
use the combined quality sensor's `signal_level` attribute in automations.
Existing numeric polling options are retained as Custom.

This release makes the repository available through HACS custom repositories;
inclusion in HACS's default catalog requires a separate review by HACS.
